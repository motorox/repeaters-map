🚀 Quick Start

Option 1: Standalone Map (Fastest)

Simply open osm.html or visit the live map

Option 2: Embed Script (WordPress, Websites)

Add this one line to your page:

<div class="repeaters-map" data-width="100%" data-height="600px"></div>
<script src="https://motorox.github.io/repeaters-map/embed.js"></script>

Option 3: Iframe

Embed in an iframe:

<iframe src="https://motorox.github.io/repeaters-map/embed.html" 
        width="100%" height="600px"></iframe>

📊 Data Sources

The map aggregates repeater data from multiple reliable sources:

  • YO Database: yo6nam/yodb (Romanian repeaters)
  • HA Repeaters: Hungarian amateur radio database (FrequencyBook, RepeaterBook)
  • S5 Repeaters: Slovenian amateur radio association data
  • YT Repeaters: Serbian/Yugoslav repeater database

Auto-refresh: Configure auto-refresh interval in config.js to keep data fresh.

❓ FAQ

Do I need to modify my site's theme?

No! The embed script works with any website or CMS. Just add a div and the script tag.

Is it free to use?

Yes! The entire project is open source under MIT license. Map tiles and APIs are free with usage limits.

Can I customize the map appearance?

Absolutely. Edit src/config.js to change colors, default location, zoom levels, and more.

What if the data is outdated?

The map loads live data from source APIs. Enable auto-refresh in config to update periodically.

How do I report incorrect data?

Check the original data sources (yo6nam/yodb, RepeaterBook, etc.) and contact them directly.

Can I use this offline?

Not by default (needs internet for map tiles and data), but you can create a local version with offline tiles.
